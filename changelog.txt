v0.2.3.3
- Publicized ICheckItemUse interface for crossmod use
- Added CheckItem.RegisterMod for ICheckItemUse with weak references
- Added Lush Wood (from Verdant) Trellises

	Returns if the player is in an oasis.

	Returns all Oasis bounding boxes in the current world.
